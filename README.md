## the-grind

The research platform the work runs on — reconnaissance, attack-surface mapping, exploitation, PoC
generation, adversarial validation and report drafting as one continuous agent loop rather than a
scanner. Roughly 2,000 commits over four months; 19 vulnerability classes encoded as 27 executable
methodology modules (~11,400 lines); every candidate finding is benchmarked for severity against
14,617 disclosed HackerOne reports before anything is submitted. Private repository, walkthrough on
request.
